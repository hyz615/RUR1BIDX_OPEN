# Source disclosure scope

This publication contains the corresponding source material for selected copyleft
components conveyed with RUR1 BIDX, their distribution patches, necessary build
recipes, and narrowly selected relinking materials. Source-package granularity
can include permissively licensed files that form part of the same upstream
source package; those files retain their original licenses.

The application communicates with independent engine/editor/storage services.
This publication does not grant an open-source license to unrelated RUR1 BIDX
business code and does not impose a common license on every component.

The source catalog distinguishes a source's provenance and availability from a
legal conclusion about an entire linked executable or service. See the audit
records for known limitations, including the existing NInfer GPL/CUDA combination
and any upstream native-binary build provenance that could not be established.

For modified MPL-covered files, the relevant source and modifications are included.
For AGPL components, source availability for binary recipients does not replace
any applicable source-offer obligation to users of a modified network service.
SSPL components keep their own terms and are not described as OSI-approved
open-source software. License texts within source archives remain authoritative.

Private credentials, deployment state, customer documents, business databases,
model weights, build-host personal paths and the RVX application's Git history
are outside the export allowlist.
