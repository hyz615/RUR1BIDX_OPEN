The helper sources and original compiler flags are included. To rebuild with a modified LGPL library, install a compatible development toolchain containing that library, adapt the output paths in build-config.json, and run the included build-static-helpers.py with --config build-config.json --source-root sources --output-dir <new-provenance-directory> --builder <your-immutable-builder-reference>. Copy LICENSE and NOTICE into sources/ before that command. BUILD.json identifies the exact original libc and GCC runtime source packages, static-input hashes, compiler commands and output hashes. The application's build provenance does not prohibit replacing these helpers with your rebuilt versions.
